# Calibration literature (references behind the Calibrator design)

Collected for the library paper. Status tags: **[verbatim]** = the cited statement was read in the source text; **[abstract]** = only the abstract/record was read; **[summary]** = seen only in a tool-generated summary, check before citing; **[knowledge]** = standard reference, not re-read.

## Scale-aware (relative) Tikhonov regularization: `regularization_weight`, `regularization_reference`

The penalty is `λ Σ_i log(p_i / p_ref,i)^2`, the MAP term of independent log-normal priors around `p_ref`; to first order it equals the relative deviation `(p_i − p_ref,i)/p_ref,i`, i.e. generalized Tikhonov with `W = diag(1/p_ref)`.

- Hoerl, A. E., Kennard, R. W. (1970). Ridge regression: biased estimation for nonorthogonal problems. *Technometrics* 12(1):55–67. Ridge on standardized predictors. [knowledge]
- Hastie, T., Tibshirani, R., Friedman, J. (2009). *The Elements of Statistical Learning*, 2nd ed., Springer, §3.4.1. Ridge solutions are not equivariant under scaling of the inputs, so inputs are standardized first. [knowledge; secondary sources and glmnet's default `standardize=TRUE` agree]
- Tikhonov, A. N., Arsenin, V. Y. (1977). *Solutions of Ill-Posed Problems*. Winston. [knowledge]
- Hansen, P. C. (1998). *Rank-Deficient and Discrete Ill-Posed Problems*. SIAM. Generalized Tikhonov `‖L(x − x*)‖²`. [knowledge]
- Tarantola, A. (2005). *Inverse Problem Theory and Methods for Model Parameter Estimation*. SIAM. Penalty = inverse prior covariance; positive "Jeffreys parameters" are treated on a logarithmic scale. [knowledge]
- Gábor, A., Banga, J. R. (2015). Robust and efficient parameter estimation in dynamic models of biological systems. *BMC Systems Biology* 9:74, doi:10.1186/s12918-015-0219-2. Regularized calibration of nonlinear dynamic models: `Γ(θ) = (θ−θref)ᵀ WᵀW (θ−θref)`, "W … is a diagonal scaling matrix and θref … is a reference parameter vector" [verbatim]; "(robust) generalized cross validation method as the most reliable" for choosing α [verbatim]; `W = diag(1./θref)` for good priors, and weighting by poor guesses amplified errors [summary].
- Raue, A. et al. (2013). Lessons learned from quantitative dynamical modeling in systems biology. *PLoS ONE* 8(9):e74335. Log-scale parameters. [knowledge]
- Schmiester, L. et al. (2021). PEtab — interoperable specification of parameter estimation problems in systems biology. *PLoS Comput. Biol.* 17(1):e1008646. Log10 parameter scale by default, priors on the parameter scale. [PEtab.jl docs read; paper itself knowledge]
- Li, X., Grandvalet, Y., Davoine, F. (2018). Explicit inductive bias for transfer learning with convolutional networks (L2-SP). *ICML*, arXiv:1802.01483. Penalize the distance to a reference (starting) point instead of zero. [abstract]
- Kirkpatrick, J. et al. (2017). Overcoming catastrophic forgetting in neural networks (EWC). *PNAS* 114(13):3521–3526. Per-parameter (Fisher) weighting of the deviation penalty. [knowledge]
- Golub, G. H., Heath, M., Wahba, G. (1979). Generalized cross-validation as a method for choosing a good ridge parameter. *Technometrics* 21(2):215–223. [knowledge]

## Optimizer scaling (`least_squares(x_scale=...)`, evaluated, default kept)

The calibrator uses scipy's default `x_scale=1.0`: `"jac"` and `|x0|` gave the same minima on the demo scenarios, and `"jac"` stalled when the start lies on a bound (ADR-0013).


- Moré, J. J. (1978). The Levenberg–Marquardt algorithm: implementation and theory. In *Numerical Analysis*, LNM 630, Springer, 105–116. Variable scaling by the inverse Jacobian column norms (scipy `least_squares(x_scale="jac")` cites it). [scipy docs verbatim]
- Branch, M. A., Coleman, T. F., Li, Y. (1999). A subspace, interior, and conjugate gradient method for large-scale bound-constrained minimization problems. *SIAM J. Sci. Comput.* 21(1):1–23. The TRF method. [knowledge]
- Dennis, J. E., Schnabel, R. B. (1996). *Numerical Methods for Unconstrained Optimization and Nonlinear Equations*. SIAM Classics, ch. 7 (scaling by typical magnitudes). [knowledge]

## Residual choice, regime imbalance, windows, bounds

- Box, G. E. P., Hunter, W. G., MacGregor, J. F., Erjavec, J. (1973). Some problems associated with the analysis of multiresponse data. *Technometrics* 15(1):33–51. Linear dependencies among measured responses make the multiresponse covariance singular, so dependent responses must be removed; independent responses are all kept (ML). [knowledge]
- Bard, Y. (1974). *Nonlinear Parameter Estimation*. Academic Press. Weighted least squares with inverse noise variances as ML. [knowledge]
- Qu, X., Wang, S., Zhang, J. (2015). On the fundamental diagram for freeway traffic: a novel calibration approach for single-regime models. *Transportation Research Part B* 73:91–102, doi:10.1016/j.trb.2015.01.001. Weighted least squares "that addresses the sample selection bias problem" of unevenly distributed (mostly free-flow) speed–density data [abstract]; exact weight formula not read (closed access).
- Yang, Y., Zha, K., Chen, Y.-C., Wang, H., Katabi, D. (2021). Delving into deep imbalanced regression. *ICML*, arXiv:2102.09554. Label distribution smoothing: effective density `p̃(y′) = ∫ k(y, y′) p(y) dy` with a symmetric (e.g. Gaussian) kernel over equal-width bins, loss re-weighted "by the inverse of the LDS estimated label density" [verbatim]; kernel size 5 / σ = 2 [summary].
- Shimodaira, H. (2000). Improving predictive inference under covariate shift by weighting the log-likelihood function. *J. Statistical Planning and Inference* 90(2):227–244. Under a correctly specified model the unweighted MLE is optimal; density-ratio weighting pays off only under misspecification. [knowledge]
- Kish, L. (1965). *Survey Sampling*. Wiley. Effective sample size `n_eff = (Σw)² / Σw²` shrinks under unequal weights. [knowledge]
- Ljung, L. (1999). *System Identification: Theory for the User*, 2nd ed. Prentice Hall. k-step-ahead prediction-error methods. [knowledge]
- Bock, H. G. (1983). Recent advances in parameter identification techniques for ODE. In *Numerical Treatment of Inverse Problems in Differential and Integral Equations*, Birkhäuser, 95–121. Multiple shooting. [knowledge] Peifer, M., Timmer, J. (2007). Parameter estimation in ordinary differential equations for biochemical processes using the method of multiple shooting. *IET Systems Biology* 1(2):78–88. Multiple shooting reduces local minima. Table I default bounds τ ∈ [15, 60] s, η ∈ [15, 60], κ ∈ [5, 60], α ∈ [0.5, 5] (no δ/φ terms in their model), "loosely based on commonly used ranges" from Poole & Kotsialos (2016) and Frejo et al. - Wang, Y., Papageorgiou, M. (2005). ## Publication notes (maintainer request 2026-11-12: recall when updating the paper)

- Ground truth decision: all simulation demos, docs examples and the calibration demo use τ 22 s, ν 15, κ 10, δ 1.4, φ 10, α 2 (bottleneck flows ≤ 1.09× capacity; within Zhao et al. 2025 Table 2 calibrated ranges). Kotsialos et al. (2002) values are the calibration start values and the cited standard set. Demo horizons per scenario (`SCENARIO_DURATIONS`): network empties shortly before the end (A 3900 s, B 4000, C-family 6000, D 3800, E-family 5700).

- The Calibrator now starts every window from a centred moving average over k = 5 samples (default), while residual targets stay raw. This is the main accuracy lever on noisy data and must be described in the paper. Numbers (job-tmp study, network C, independent noise σ = 5/10/5 % of mean q/ρ/v, 3 seeds): demo truth mean parameter error free/mixed/congested 4.4/8.7/15.1 % → 1.4/2.8/5.1 % (oracle with clean initial states 0.9/0.9/3.5 %). Trade-off: on noise-free data k = 5 biases the estimate by ≤ 0.75 % (demo truth) but up to 26 % for the weakly identified literature truth (free flow), so exact-data examples use k = 1.
- The literature truth (τ 18 s, ν 65, κ 40, a 1.867) is practically non-identifiable in ν vs κ with these data (oracle ≈ 19 % in mixed/congested); priors (λ > 0) help only if near the truth.
- Rejected with evidence (ADR-0013/0014): dropping a residual, density-bin / LDS weighting, multiple shooting with free window states, `x_scale="jac"`, literature bounds.
