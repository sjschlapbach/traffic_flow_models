    Calibration

    Experimental

    Calibration tooling is experimental. The API may change in future releases.

    Parameter calibration fits METANET model parameters to reference data (e.g. measured traffic data or the output of another simulator, converted to the ground-truth file format) using sliding-window nonlinear least-squares optimisation via SciPy's Trust-Region Reflective algorithm. Only METANET supports calibration; CTM has no calibratable parameters (its characteristics are entirely determined by link geometry).

    For a detailed algorithmic description, see Schlapbach et al., STRC 2026.

    Overview

    The calibration workflow:

    1. Provide ground-truth data as a results JSON file (e.g. saved from a reference simulation with Simulation.save_results, or converted from measurements).
    2. Instantiate a Calibrator with the same Network object.
    3. Call calibrate_model_params() with the path to the saved JSON.
    4. Optionally run multi-start search (Latin Hypercube Sampling) to escape local minima, and inspect parameter correlations to detect identifiability issues.

    Basic usage

    from traffic_flow_models import Calibrator, METANET, METANETParams

# Initial parameter guess (the model's literature start values)
initial_params: METANETParams = {
    "tau": 18.0 / 3600,
    "nu": 60.0,
    "kappa": 40.0,
    "delta": 0.0122,
    "phi": 2.98,
    "alpha": 1.636,
}

metanet = METANET()

# Create the calibrator (takes only the network)
calibrator = Calibrator(network=net)

# Calibrate — returns (params_dict, scipy_result, param_history_array)
calibrated_params, result, param_history = calibrator.calibrate_model_params(
    # ground truth file in the results JSON format (see below)
    ground_truth_filepath="results/ground_truth/simulation_results.json",
    model=metanet,
    initial_params=initial_params,
    window_size=30,       # time steps per sliding window
    stride=15,            # step between windows (default: window_size // 2)
    model_options={"link_specific_alpha": False},
    regularization_weight=0.0,
    max_nfev=200,
    verbose=True,
    save_dir="results/calibration",
    plot_correlation="parameter_correlation.png",
    plot_param_history="param_history.png",
    correlation_title="Parameter Correlation Analysis",
)

print(calibrated_params)          # METANETParams dict with calibrated values
print(f"Cost:    {result.cost:.4e}")
print(f"Success: {result.success}")
print(f"Evals:   {result.nfev}")

    The calibration targets the six METANETParams fields: tau, nu, kappa, delta, phi, and alpha. Fundamental-diagram parameters (lane_capacity, free_flow_speed, jam_density) are not calibrated — they stay on the links.

    Return values

    Value Type Description
    calibrated_params METANETParams Calibrated parameter dict
    result scipy.OptimizeResult Full optimizer state (result.cost, result.success, result.nfev, result.message)
    param_history NDArray[float] 2-D array (n_evals × n_params) — parameter vector at each residual evaluation

    Ground-truth file format

    The ground truth is a JSON file with the same layout that Simulation.save_results writes and Simulation.load_results reads. Link, node, origin and destination IDs must match the Network passed to the Calibrator.

    {
  "metadata": { "model_type": "METANET", "link_properties": { "...": {} } },
  "time_array": [0.0, 0.0028, 0.0056],
  "state_time_series": {
    "flows":     { "<link_id>": [[q_cell0, q_cell1], [q_cell0, q_cell1], ...] },
    "densities": { "<link_id>": [[...], ...] },
    "speeds":    { "<link_id>": [[...], ...] },
    "origin_queues": {}, "onramp_queues": {}, "offramp_queues": {}
  },
  "disturbance_time_series": {
    "origin_demands": {}, "turning_rates": {},
    "flow_boundary_conditions": {}, "density_boundary_conditions": {}
  }
}
    • time_array is in hours. State series hold one entry per time step (per-cell lists for motorway links). Disturbance series hold one entry fewer, since they apply between steps.
    • Full files (use_disturbance_from_file=True, the default) must contain all state fields (including the queue fields) and all four disturbance fields.
    • Mainline-only files (use_disturbance_from_file=False) only need flows, densities and speeds for the mainline motorway links, plus the two boundary-condition fields. Queues are optional (zero when absent); demands and turning rates are not read from the file. Instead, all four disturbance callables (origin_demands_fn, turning_rates_fn, flow_boundary_conditions_fn, density_boundary_conditions_fn) must be passed. Set metadata.model_type to "MICRO" so that Simulation.visualize and visualize_comparison also load the file in mainline-only mode.
    • Ramp metering: On-ramp controllers of the network are evaluated inside the model step on the predicted states. If a controller sets control_dt (see Ramp metering), the calibrator instead reconstructs the metering rates of all on-ramps once from the recorded states, since the model step then takes every rate as an input: rates of controllers with a control_dt are held for it, as Simulation.run does, and controllers without one are updated at every step. This needs a full file, a time step that divides control_dt, and a series that starts with a controller update (as files from Simulation.save_results do).
    • If the number of cells per link in the file differs from the network partitioning, the per-cell arrays are resampled spatially, using metadata.link_properties[<id>].cell_lengths when present (uniform cells otherwise). Use Simulation.resample_results_file to resample a file to a different time grid.

    Custom bounds

    The default start values are the model parameters of Kotsialos, Papageorgiou, Mangeas and Haj-Salem (2002, Transportation Research Part C 10(1), 65–84, Table 1): \(\tau = 18\) s, \(\nu = 60\) km²/h, \(\kappa = 40\) veh/km/lane, \(\delta = 0.0122\), \(\varphi = 2.98\) and \(a = 1.636\). The default bounds are the METANET calibration limits of Zhao, Roncoli and Yildirimoglu (2025, Bounded-METANET, Table 1): \(a \in [0.5, 2.5]\), \(\tau \in [5, 80]\) s, \(\nu \in [10, 90]\) km²/h, \(\kappa \in [5, 50]\) veh/km/lane, \(\delta \in [10^{-4}, 4]\), with \(\varphi \in [0.01, 15]\) (no published range). The explicit relaxation term is unstable for \(\tau\) below the time step \(T\) (Zhao et al. note that the lower bound of \(\tau\) is set by the time step), so the calibrator raises a lower bound of \(\tau\) below \(T\) to \(T\) and issues a warning; this applies to the default bounds and to param_bounds. Start values and true values should lie strictly inside the bounds.

    Retrieve the model's default bounds and optionally override them:

    import numpy as np

lower, upper = METANET().get_calibration_bounds(network=net)

# Override specific bounds (order: tau, nu, kappa, delta, phi, alpha)
lower[0] = 20.0 / 3600  # tau ≥ 20 s
upper[1] = 60.0         # nu ≤ 60

calibrated_params, result, param_history = calibrator.calibrate_model_params(
    ground_truth_filepath="results/ground_truth/simulation_results.json",
    model=metanet,
    initial_params=initial_params,
    param_bounds=(lower, upper),
    window_size=30,
    stride=15,
    model_options={"link_specific_alpha": False},
)

    Multi-start search

    When data are noisy or the loss surface is multimodal, use Latin Hypercube Sampling to explore the parameter space from multiple starting points. The best result across all runs is returned. Pass plot_convergence as a filename string to save a diagnostic plot of cost, evaluations, and optimality across all LHS runs:

    calibrated_params, result, param_history = calibrator.calibrate_model_params(
    ground_truth_filepath="results/ground_truth/simulation_results.json",
    model=metanet,
    initial_params=initial_params,
    window_size=30,
    stride=15,
    model_options={"link_specific_alpha": False},
    regularization_weight=0.0,
    max_nfev=150,
    use_parameter_search=True,     # enable LHS multi-start
    n_samples=40,                  # number of LHS samples
    save_dir="results/calibration",
    plot_convergence="lhs_convergence.png",   # convergence across LHS runs
    plot_correlation="parameter_correlation.png",
    plot_param_history="param_history.png",
    convergence_title="Multi-Start Convergence",
    correlation_title="Parameter Correlation — LHS Best",
    verbose=True,
)

    plot_convergence only produces output when use_parameter_search=True; it is silently ignored in single-start mode. Both plot_convergence and plot_correlation also accept True (uses a default filename) or False (disabled).

    Correlation analysis

    High off-diagonal correlations (> 0.8) indicate parameter pairs that cannot be identified simultaneously. The analysis is triggered automatically during calibrate_model_params() when plot_correlation and save_dir are set. It can also be run standalone on a result returned from a previous call:

    param_names = METANET().get_calibration_param_names(network=net)
# returns ['tau', 'nu', 'kappa', 'delta', 'phi', 'alpha']

calibrator.analyze_parameter_correlation(
    result=result,
    param_names=param_names,
    save_dir="results/calibration",
    filename="correlation_matrix.png",
    title="Parameter Correlation Analysis",
)

    If a pair is strongly correlated, consider fixing one parameter to a physically motivated value by narrowing its bounds to a small interval around that value, then re-running.

    Regularization and noisy data

    Each calibration window starts from the recorded state at its first time step and is predicted forward with the candidate parameters. With noisy data, this initial state is itself noisy, which biases the estimate. The calibrator therefore starts every window from a centered moving average of the recorded states, \(\hat{x}(t) = \frac{1}{|N_t|} \sum_{j \in N_t} x(j)\) with \(N_t = \{t - \tfrac{k-1}{2}, \dots, t + \tfrac{k-1}{2}\}\) restricted to the recorded time steps (initial_state_smoothing \(k\), odd, default 5; with 10 s steps about a 1-minute aggregation). The residuals still compare with the raw measurements. Use initial_state_smoothing=1 for noise-free data. The starting point is moved 0.1 % of the bound range inside the parameter bounds, because the trust region reflective method stalls when it starts on a bound.

    For noisy real-world data, three further strategies improve robustness:

    1. Disable link-specific alpha (link_specific_alpha: False) to reduce the number of free parameters.
    2. Add relative Tikhonov regularization (regularization_weight \(\lambda\)) to penalize deviation from the reference parameters \(p^{\mathrm{ref}}\) (regularization_reference, default initial_params; with multi-start every run uses the same reference). The calibrator minimizes \(\lVert r(p) \rVert^2 + \lambda \sum_i \log^2(p_i / p_i^{\mathrm{ref}})\), the MAP objective of independent log-normal priors. The penalty is unit-free, so a deviation by a factor of 2 costs \(\lambda \log^2 2 \approx 0.48\,\lambda\) for every parameter (e.g. tau in hours and nu in km²/h alike). It requires positive parameters and lower bounds.
    3. Use multi-start search to avoid local minima introduced by noise.
    # Experiment: noisy data with relative Tikhonov regularization (no multi-start)
calibrated_params_reg, result_reg, param_history_reg = calibrator.calibrate_model_params(
    ground_truth_filepath="results/noisy/simulation_results.json",
    model=metanet,
    initial_params=initial_params,
    window_size=30,
    stride=15,
    model_options={"link_specific_alpha": False},
    regularization_weight=0.1,     # relative (log-ratio) Tikhonov penalty
    use_parameter_search=False,
    save_dir="results/calibration",
    plot_correlation="noisy_reg_correlation.png",
    plot_param_history="noisy_reg_param_history.png",
    correlation_title="Parameter Correlation — Noisy (Regularized)",
)

    Link-specific alpha

    Set model_options={"link_specific_alpha": True} to calibrate a separate alpha for every motorway link. The returned calibrated_params["alpha"] is then a dict[str, float] mapping link IDs to values rather than a scalar:

    calibrated_params_link, result_link, param_history_link = calibrator.calibrate_model_params(
    ground_truth_filepath="results/noisy/simulation_results.json",
    model=metanet,
    initial_params=initial_params,
    window_size=30,
    stride=15,
    model_options={"link_specific_alpha": True},
    regularization_weight=0.1,
    use_parameter_search=False,
    save_dir="results/calibration",
    plot_correlation="link_alpha_correlation.png",
    plot_param_history="link_alpha_param_history.png",
    correlation_title="Parameter Correlation — Link-Specific Alpha",
)

# calibrated_params_link["alpha"] is a dict when link_specific_alpha=True
alpha = calibrated_params_link["alpha"]
if isinstance(alpha, dict):
    for link_id, alpha_val in alpha.items():
        print(f"  Link {link_id}: alpha = {alpha_val:.4f}")
else:
    print(f"  Global alpha = {alpha:.4f}")

    Comparing parameter histories

    After running multiple experiments you can overlay their parameter trajectories to compare convergence across conditions:

    param_names = ["tau", "nu", "kappa", "delta", "phi", "alpha"]

calibrator.plot_parameter_convergence(
    param_history_exact=param_history_exact,     # from exact ground truth
    param_history_noreg=param_history_noreg,     # from noisy data, no regularization
    param_history_reg=param_history_reg,         # from noisy data, with regularization
    param_names=param_names,
    true_params=true_params,                     # METANETParams ground truth (for reference lines)
    save_dir="results/calibration",
)
